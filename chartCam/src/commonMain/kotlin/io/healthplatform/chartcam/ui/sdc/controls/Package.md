# Package io.healthplatform.chartcam.ui.sdc.controls

Visual Form Controls for FHIR Structured Data Capture (SDC).

## Overview
This package encapsulates interactive Compose Multiplatform visual clinical controls including Wong-Baker FACES / VAS pain scales, Fitzpatrick skin phototype palettes, anatomical body-map pin-drop interfaces, and segmented choice tiles. Ensure 100% test and documentation coverage for all public entities in this module.
